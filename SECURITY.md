# Security

Report vulnerabilities privately through [GitHub's Report a vulnerability](https://github.com/Krishnapthm/canopy/security/advisories/new). Don't post exploit details in a public issue.

Include the Canopy version (`canopy --version`), OS, what you found, steps to reproduce it, and the impact. A small proof of concept helps. Remove secrets and personal data from logs.

Only the latest release is supported.

Problems in herdr-core itself belong to its own project. For how Canopy handles trusted mods and telemetry, see [security and privacy](https://github.com/Krishnapthm/canopy/wiki/Security-and-Privacy).
