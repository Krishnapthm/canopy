# Glossary

The words these pages use, each with one meaning.

| Word | Meaning |
|---|---|
| Agent | A coding agent CLI, such as Claude Code or Codex, running in a terminal pane. Canopy lists only the agents installed on your computer. |
| App home | The folder that holds your settings, keys, layouts and mods. The default is `~/.config/canopy`. |
| Canvas | The free surface that holds your panes. You pan, zoom and arrange it. |
| Canvas mode | The canvas has the keyboard, so single keys act on panes. No pane is entered. |
| Collapsed pane | A terminal pane drawn as a small pill with its name. |
| Core | [herdr-core](herdr-core), the separate program (`hc`) that runs your terminals. |
| Entered pane | The expanded pane that has the keyboard. |
| Envelope | The `<pane-content>` wrapper around pane text that an agent reads. It marks the text as data, not a request. |
| Expanded pane | A terminal pane drawn as a full, live terminal. |
| Files panel | The side panel with the file browser, file previews and changes. |
| Helper bar | The small row of buttons above a pane you hover or select. |
| Home | The view that shows every space as a card. |
| Label | A small value that herdr-core stores on a terminal. All apps connected to the core see it. |
| Layout | A JSON file that arranges the window. |
| Machine | A computer with herdr-core that Canopy reaches over SSH. |
| Mod | A JavaScript add-on that draws part of the window or a kind of pane. |
| Pane | Anything on the canvas: a terminal, agent, sub-agent, file, note, image, PDF, browser, simulator or mod pane. |
| Peer | A pane wired to your pane. |
| Quote | A selection from a pane, pasted into an agent's input without pressing Enter. |
| Skill | The `canopy` instructions that agents load to learn Canopy. |
| Space | A room for one project folder. It has its own canvas, name and color. |
| Sub-agent | A helper that an agent starts. It shows beside its parent, joined by an edge. |
| Tile view | A view that fits your panes into an even grid. |
| Toolbar | The bar at the bottom of the canvas with tools and new panes. |
| Top strip | The bar at the top of the window with Home, the space tabs and the view buttons. |
| Wire | A line between two panes. It introduces peers. It does not carry or limit messages. |
