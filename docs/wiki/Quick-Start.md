# Quick Start

Open a project, start agents and wire their panes.

## Install

1. Follow the [install instructions](https://github.com/Krishnapthm/canopy#install).
2. Open Canopy from your apps.
3. Click **Next** in **Welcome to Canopy**.
4. Click **Not now** if you have no machines. Otherwise, click **Next**.
5. Click **Next**.

## Open your project

1. Click **Open a space**.
2. Click **Add** beside **Folder**.
3. Click **Choose**.
4. Select your project folder.
5. Click **Open space**.

## Start an agent

1. If **Teach agents Canopy** opens, press `Esc`.
2. Click **Terminal** on the toolbar to open a terminal pane.
3. Click **Agent** on the toolbar.
4. Select an agent from the menu.
5. Type your task in the agent pane.

## Wire two agents

1. Click **Agent** on the toolbar again.
2. Select an agent for the second pane.
3. Hover over the first agent pane.
4. Click its **+** handle.
5. Click the second agent pane.
