# Linux Desktop

Canopy uses the same settings, themes and in-app toasts on Linux and macOS.

## Main Menu

Click **Main Menu** in the window header or press **F10**. Settings, Keyboard
Shortcuts and Welcome are on the first page. Use the arrow keys to move,
Enter to choose, Left or Back to return to the first page, and Esc to close.
Press **Ctrl+,** to open [Settings](Settings-and-Themes) directly.

## Window controls and launcher

Canopy uses the desktop's window frame when available. On desktops such as
GNOME Wayland, Canopy draws the frame using the desktop's button layout and
the window controls it supports. Layouts with their own title bars draw
their own controls.

Launching from Applications or the CLI groups Canopy's windows under one
Canopy dock icon. The Linux app ID and X11 window class match the
`canopy.desktop` launcher shipped by both installers.
