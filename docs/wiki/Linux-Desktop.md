# Linux Desktop

Canopy uses the same settings, themes and in-app toasts on Linux and macOS.

## Main Menu

Click **Main Menu** in the top strip above the canvas or press **F10**.
Settings, Keyboard Shortcuts and Welcome are on the first page. Use the arrow
keys to move, Enter to choose, Left or Back to return to the first page, and
Esc to close.
Press **Ctrl+,** to open [Settings](Settings-and-Themes) directly.

## Window controls and launcher

Drag an empty part of the top strip to move the window. Double-click there
to maximize or restore the window when your desktop supports that action.

Canopy uses the desktop's window frame when available. When Canopy draws the
frame, the top strip holds both the canvas controls and the window buttons.
The window buttons follow your desktop's order and sit at the outer edge.
**Main Menu** sits on the left, or on the right when there are window buttons
on the left. Popped-out panes keep a separate window header when Canopy draws
the frame. Other layouts with custom title bars supply their own controls.

Launching from Applications or the CLI groups Canopy's windows under one
Canopy dock icon. The Linux app ID and X11 window class match the
`canopy.desktop` launcher shipped by both installers.
