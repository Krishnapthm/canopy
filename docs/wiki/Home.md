# Canopy

Canopy is a desktop app for terminals and coding agents. Put them on one canvas, wire them together, and see which agent needs you.

![A canvas with agents, a terminal, a browser pane and a simulator](images/home-1.png)

Terminals keep running when you close the window, because [herdr-core](herdr-core) runs them.
Canopy works with the agent CLIs you already use. It does not wrap or replace them.

## Start here

1. Install Canopy with the one-line command in the [README](https://github.com/Krishnapthm/canopy#install).
2. Follow the [Quick Start](Quick-Start).
3. Look up a word in the [Glossary](Glossary).

Something wrong? See [Troubleshooting](Troubleshooting).
