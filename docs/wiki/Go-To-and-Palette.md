# Go To and Palette

Two keyboard-first ways to get around. **Go to** jumps to a space, terminal or open file by typing part of its name. The **command palette** runs any app command by name, and shows its shortcut so you learn the key for next time. Both work the same in every layout.

## Go to

1. Press `Cmd+K` or `Cmd+P` (`Ctrl+Shift+K` on Linux and Windows) to open **Go to**.
2. Type a name to search spaces, live terminal panes and open file tabs.
3. Press `Up` or `Down` to select a result.
4. Press `Enter` to open it.

Both searches match letters in order, ignore case and allow gaps between letters.

Press `Esc` to close **Go to**.

## Command palette

![The command palette](images/go-to-and-palette-1.png)

1. Press `Cmd+Shift+P` (`Ctrl+Shift+P` on Linux and Windows) to open the command palette.
2. Type a command name.
3. Press `Up` or `Down` to select a command.
4. Press `Enter` to run it.

The palette shows assigned global shortcuts beside command names.
Press `Esc` to close the palette.

See [Commands](Commands) for the full command list.
See [Keys and Mouse](Keys-and-Mouse) to change shortcuts.
