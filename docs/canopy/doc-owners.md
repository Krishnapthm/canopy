# Wiki owner map

Each fact has one page. This map says which. A page links to the owner page
for anything outside its own list and never restates it. Each block below is
also the brief for the session that writes that page.

"Old" means the text on main before the wiki move. Read it with
`git show origin/main:docs/<file>`. It is a source of facts, not of wording:
it is often internal detail the reader does not need.

Shots: the orchestrator takes the screenshots. Put each image line where the
block says, with the exact file name and alt text, even before the file exists.

Home, Glossary, Simulator-Devices (the gold-standard example), _Sidebar,
_Footer, and Commands (generated by `scripts/docs.ts`). README owns install,
