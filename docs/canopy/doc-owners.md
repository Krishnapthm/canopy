# Wiki map

Which page owns which facts, so each fact is stated in full in one place. Other
pages may restate a fact in a sentence to save the reader a click, using the
same values, and link here for the rest. The style is in
[doc-style.md](doc-style.md).

When you change a feature, update its owner page. When you add a feature, give
it an owner here and list the page in `docs/wiki/_Sidebar.md`.
