a desktop workspace for your coding agents

run your agents and terminals on a canvas alongside your files, a browser and an ios simulator, so you can see what they’re working on and when they need you.

get canopy quick start

try the canvas by dragging a pane by its header or grabbing the phone.

connect your agents. draw a wire between two agent panes so they can find and message each other. you can ask one agent to review a diff and send its feedback directly to the agent that wrote it.

test your ios app. on macos, keep the ios simulator next to your agent while it taps and scrolls through your app. if you spot a bug, mark it on the screen and send the annotated screenshot to the agent.

work with project files. browse and edit your project files from the files panel, or open one beside an agent. select a few lines to quote them in its prompt with the file path and line numbers.

questions

what is canopy?

each project gets a canvas for its agents, terminals and files. on macos, you can also open your dev server in a browser pane, mark up what you see and share that context with the agent working on it.

what inspired canopy?

i wanted the freedom to arrange my tools the way i arrange things in figma, with the agent workflows i like in claude code and the claude desktop app. canopy started as a fork of herdr-app.

which coding agents can i use?

if an agent runs in your terminal, you can run it in canopy using your existing login. canopy detects installed clis such as claude code and codex and lets you launch them in your project folder.

how is canopy built?

canopy is a native rust app that uses gpui, the gpu-accelerated ui framework behind zed.

what happens when i quit canopy?

your agents and terminals keep running in herdr core even if you quit canopy or the window crashes. when you reopen canopy, you can pick up the same sessions.

how is canopy related to herdr?

herdr core is the runtime for your terminal sessions and coding agents. canopy connects to it and shows those sessions on the canvas. herdr uses the same runtime.

which operating systems does canopy support?

canopy runs on apple silicon macs and linux. the built-in browser and ios simulator panes are available on macos.

where does my code go?

canopy works with your project files locally and has no telemetry. the agents you run in it use their own providers and follow those providers’ data policies.

is canopy free?

canopy is free and open source under the apache 2.0 license. any coding agent subscriptions you use are separate.

get canopy

macos and linux

curl -fsSL https://github.com/Krishnapthm/canopy/releases/latest/download/install.sh | sh

the installer sets up the herdr core runtime if you need it. once canopy opens, the quick start walks you through your first project.
