open canvas for your coding agents

run coding agents, terminals, simulators, browsers and project files on a single canvas.

built with rust, open source

get canopy quick start

move things around. arrange your agents terminals and tools on the canvas however you like, without being confined to tabs or split panes.

let your agents work together draw a wire between two agent panes so they can find and message each other. you can ask one agent to review a diff and send its feedback directly to the agent that wrote it.

test and debug your app open a simulator right next to your agent while it taps and scrolls through your app. if you spot a bug, mark it on the screen and send the annotated screenshot to the agent. iOS only, android coming soon.

work with project files browse and edit your project files from the files panel, or open one beside an agent. select a few lines to quote them in its prompt with the file path and line numbers.

questions

which coding agents can i use?

any coding agent that runs in your terminal.

what happens when i close canopy?

your agents and terminals continue running in the background, even if canopy crashes. reopen canopy and pick up where you left off.

which platforms are supported?

macOS and Linux. iOS simulators on macOS is supported for now. android simulator and windows support otw.

how is canopy related to herdr?

canopy is a fork of herdr. it uses herdr-core under the hood for the terminal sessions and coding agents.

get canopy

macOS and Linux

curl -fsSL https://github.com/Krishnapthm/canopy/releases/latest/download/install.sh | sh

the installer sets up the herdr-core runtime if you need it. once canopy opens, the quick start walks you through your first project.
